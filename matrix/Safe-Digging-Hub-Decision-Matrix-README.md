# Safe Digging Hub Decision Matrix v1

This package establishes the linked source-of-truth model for the Safe Digging Hub v3.

## Workbook tabs

- Overview
- Personas
- Intents
- Methods
- Jurisdictions
- Risks
- Mitigations
- Library
- Legislation
- Services
- OneCall Mapping
- Recommendation Rules
- Change Log

## Product hierarchy

Guidance and understanding first; risk and mitigation second; actions and services third; site information only where required; OneCall suggestions only after Utility Search is selected and always confirmed by the user.

## Governance

The matrix is a product model, not legal or engineering advice. Safety-critical content and nation-specific legislation must be reviewed by competent owners.
