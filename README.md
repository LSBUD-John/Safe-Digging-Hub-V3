# Safe Digging Hub v3

A clean conversational prototype for a guidance-first UK Safe Digging Hub.

## Brand

**Safe Digging Hub**  
Delivered by LSBUD

## Prototype

The visitor describes an activity, answers one question at a time, receives free guidance and risk considerations, and sees site-specific services only where relevant. Utility Search is a recommendation rather than the starting point.

## Deploy

Upload the repository contents and enable GitHub Pages from the main branch root.


## Journey layout

The active journey uses a persistent left-hand **What we understand** panel. Answers accumulate in the panel while progressive questions and recommendations remain in the main content area. On narrower screens the panel moves above the active question.
