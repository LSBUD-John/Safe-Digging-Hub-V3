# Safe Digging Hub v3

A clean conversational prototype for a guidance-first UK Safe Digging Hub.

## Brand

**Safe Digging Hub**  
Delivered by LSBUD

## Prototype

The visitor describes an activity, answers one question at a time, receives free guidance and risk considerations, and sees site-specific services only where relevant. Utility Search is a recommendation rather than the starting point.
